## 시작하기

**[최신 공개 버전](https://github.com/Keegankei/KeeStashDock/releases/latest)** · **[Windows x64 ZIP — 1.2.3](https://github.com/Keegankei/KeeStashDock/releases/download/v1.2.3/KeeStashDock-1.2.3-win-x64.zip)** · [SHA-256 체크섬](https://github.com/Keegankei/KeeStashDock/releases/download/v1.2.3/KeeStashDock-1.2.3-win-x64.zip.sha256)

1. GitHub의 개발자용 **Source code** 압축 파일이 아닌, **Assets** 아래의 앱 ZIP 파일을 다운로드하세요.
2. 쓰기 가능한 폴더에 전체 압축을 풀고 `KeeStashDock.exe`를 실행하세요. 함께 제공되는 모든 폴더를 그대로 유지하세요.
3. **Alt+Q**를 눌러 빠른 패널을 표시하세요. 텍스트 조각을 입력하고 **Enter**를 누르면 저장되며, 카드를 클릭하면 복사됩니다.
4. 패널이나 시스템 트레이에서 **설정**을 열어 언어, 테마, 선택 구성 요소를 설정하세요.

Windows x64 패키지에는 .NET이 포함되어 있어 별도로 설치할 필요가 없습니다. Windows 11을 우선 대상으로 하며, Windows 10 22H2도 가능한 범위에서 지원합니다. OCR과 오프라인 번역에는 Microsoft Visual C++ 런타임이 필요할 수 있으며, 앱 내 구성 요소 설치 기능으로 설치할 수 있습니다. 검증된 범위는 [1.2.3 검증 기록](docs/releases/1.2.3.md)을 참고하세요.

<details>
<summary>다운로드한 ZIP 검증하기</summary>

다운로드 폴더에서 다음 명령을 실행하고, 함께 제공되는 `.sha256` 파일과 결과를 비교하세요.

```powershell
Get-FileHash .\KeeStashDock-1.2.3-win-x64.zip -Algorithm SHA256
```

체크섬은 파일의 무결성을 확인하는 수단이며, 게시자 서명이 아닙니다. 현재 패키지에는 서명이 없습니다.

</details>

**새 설치 기본값 · 1.2.3:** 화면 언어는 영어입니다. **Alt+Q**로 패널을 열고 **Alt+W**로 스크린샷을 시작합니다. OCR과 로컬 번역은 사전 설치되지 않습니다. 업그레이드 시 기존 설정을 유지합니다.

선택 말풍선은 **복사만**으로 켜지고 번역 엔진은 **Google**입니다. 말풍선 스타일은 기본, 글자 발광은 끄고 그림자는 켭니다. 시작 프로그램 등록, 클립보드 자동 수집, 직접 붙여넣기는 꺼져 있습니다. 가장자리 자동 숨김은 켜지고 숨김 지연은 **2초**, 펼침 지연은 **0.1초**입니다. 시스템 테마, **표준** 모드, **오른쪽 버튼을 누른 채 드래그 검사**, 자동 글자색, 패널 컨트롤 불투명도 **90%**를 사용합니다. 배경 이미지는 없으며 오버레이 불투명도는 **20%**, 블러는 꺼져 있으며 저장된 반경은 **4 px**입니다. **24시간** 간격의 자동 백업이 켜져 있습니다.

## 기능

**1.2.3 설정:** **일반, 캡처 및 번역, 모양, 로컬 구성 요소, 백업 및 데이터, 정보** 범주로 이동할 수 있습니다. 관련 옵션은 필요할 때 표시되며, 숨겨져도 저장된 값은 유지됩니다.

**캡처 및 번역**에서 결과 창의 대상 언어 선택기와 그룹 저장 도구를 각각 켜거나 끌 수 있습니다. 둘 다 기본으로 켜져 있으며 OCR이나 번역이 끝나면 표시됩니다. 꺼도 결과를 보거나 복사할 수 있습니다.

백업 폴더는 **백업 및 데이터**에서, OCR과 오프라인 번역 폴더는 **로컬 구성 요소**에서 각각 선택하세요. 폴더를 바꿔도 **기존 파일은 이동하지 않습니다**. 새 폴더가 비어 있으면 구성 요소를 다시 설치하세요. **정보**에는 현재 앱 데이터 위치가 읽기 전용으로 표시됩니다. 라이브러리를 안전하게 옮기려면 내보내기와 가져오기를 사용하세요.

아래 미리보기는 가상의 예시 데이터를 사용한 **1.2.2의 실제 영어 화면**입니다. 표준 패널에는 새 설치의 기본 모양 설정을 적용했으며, 공간 모드와 복사 / 번역 버튼을 함께 표시하는 말풍선은 선택 가능한 설정을 보여 줍니다. 공간 모드 GIF의 포인터와 업데이트 화면의 릴리스는 시뮬레이션입니다. 설치 및 데이터 경로는 가렸으며, 개인 데스크톱이나 클립보드 내용은 포함하지 않았습니다. [이미지 출처 및 재현 방법](docs/images/README.md).

### 1. 수집, 검색, 정리

<p align="center"><img src="docs/images/main-window.png" width="900" alt="검색, 그룹, 고정한 텍스트 조각, 예시 이미지 항목을 보여 주는 워크벤치"></p>

짧은 내용을 저장할 때는 빠른 패널을, 모아 둔 내용을 관리할 때는 **워크벤치**를 사용하세요. 패널의 확장 버튼이나 트레이에서 워크벤치를 열 수 있습니다.

| 도구 | 사용 방법 |
| --- | --- |
| 빠른 입력 및 검색 | Enter로 텍스트를 저장하고, Alt+Enter 또는 Shift+Enter로 줄을 바꾸며, 워크벤치에서 항목을 검색하고 필터링합니다. |
| 도크로 끌어 놓기 | 텍스트를 놓으면 내용을 저장하고, 파일이나 폴더를 놓으면 경로를 저장합니다. 경로 카드를 클릭하면 대상을 열고, 오른쪽 클릭 메뉴의 **복사**를 선택하면 경로를 복사합니다. 파일 내용은 가져오지 않습니다. |
| 그룹, 태그, 고정 | 관련 항목을 묶고, 제목·텍스트·태그를 편집하며, 자주 사용하는 내용을 고정합니다. |
| 만료 및 휴지통 | 만료 없음, 1일, 7일, 읽은 후 삭제 중에서 선택합니다. 만료되거나 삭제된 항목은 휴지통으로 이동하며 복원할 수 있습니다. 휴지통의 항목은 기본적으로 30일 후 영구 삭제됩니다. |
| 데스크톱 메모 | 텍스트나 경로 카드를 패널 밖으로 끌면 현재 세션 동안 별도의 데스크톱 메모로 유지됩니다. 앱을 종료하면 이 메모 창은 닫히지만, 저장한 항목은 모음에 남습니다. 이미지 카드는 이미지 항목으로 남습니다. |
| QR 코드 | 텍스트 카드를 오른쪽 클릭해 최대 1,800자의 QR 코드를 표시합니다. |
| 텍스트 도구 | 워크벤치의 변환 메뉴에서 대소문자 변환, 공백 정리, JSON 서식 지정, URL 및 Base64 인코딩·디코딩을 사용합니다. |
| 그룹 가져오기/내보내기 | `.ksdgrp` 패키지를 공유하거나 Git, Docker, 셸 등 여러 도구의 명령 프리셋을 불러옵니다. 이미지가 포함된 패키지는 호환되는 앱 버전이 필요합니다. |
| 클립보드 기록 | 원하면 복사한 **텍스트**를 자동으로 수집합니다. 빈 텍스트와 너무 긴 텍스트는 무시하며, 중복 항목은 다시 추가하지 않습니다. 기본적으로 꺼져 있습니다. |
| 직접 붙여넣기 | 원하면 복사한 텍스트 항목을 이전 앱에 붙여넣습니다. 대상 창을 안전하게 확인할 수 있을 때만 실행됩니다. 기본적으로 꺼져 있습니다. |

*흰색 포인터는 가까운 카드의 반응을, 주황색 포인터는 버튼을 누른 채 끌어 시점을 조정하는 동작을 나타냅니다. 이 애니메이션은 사용 방법을 설명하는 예시이며, 프레임 속도 벤치마크가 아닙니다.*

- **시점 고정:** 일정하게 기울어진 화면을 유지하며, 가까운 카드는 포인터에 반응합니다.
- **누르고 끌어 살펴보기:** 카드 본문이나 패널 배경에서 **마우스 오른쪽 버튼**을 누른 채 끌어 보세요. 버튼을 놓으면 각도가 유지됩니다. 끌지 않고 오른쪽 클릭하면 기존과 같이 카드 메뉴가 열립니다. 설정에서 가운데 버튼이나 마우스 버튼과 보조 키의 사용자 지정 조합을 선택할 수도 있습니다.
- **축소 막대:** 패널을 접으면 최소화, 펼치기/접기, 잠금, 스크린샷, 워크벤치, 설정의 여섯 가지 동작만 남습니다. 펼치면 이전 패널 크기로 복원됩니다.
- **화면 가장자리로 끌면 자동 숨김:** 1.2.3에서는 기본으로 켜져 있습니다. 패널을 화면의 네 가장자리 중 한 곳으로 끈 뒤 포인터를 멀리 옮기세요. 작은 손잡이만 남으며, 그 위에 포인터를 올리거나 클릭하면 패널이 복원됩니다. 잠그면 패널이 계속 표시됩니다.

두 모드 모두 펼친 패널의 가장자리나 모서리를 끌어 크기를 조절할 수 있으며, 재시작 시 저장된 크기로 복원됩니다. 6개 버튼의 접힌 막대는 크기가 고정됩니다. 1.2.3은 저장된 패널 위치 복원 중의 초기화 예외를 수정하고 공간 모드의 크기 조절 영역을 실제 보이는 패널 가장자리에 맞췄습니다.

밝은 테마, 어두운 테마, 시스템 테마를 사용할 수 있으며, 사용자 지정 배경, 불투명도, 흐림 효과도 조절할 수 있습니다. 시스템의 고대비 및 애니메이션 축소 설정에 따라 정적인 화면으로 표시됩니다. [어두운 테마 미리보기](docs/images/floating-panel-dark.png) · [고정 시점 미리보기](docs/images/floating-panel-fixed.png) · [성능 측정 및 한계](docs/performance/1.2.2-floating.md).

설정에서 패널의 텍스트 색상 팔레트, 사용자 지정 글자색, 자동 대비를 선택할 수 있습니다. 텍스트 선택 말풍선의 스타일, 발광, 그림자, 불투명도도 각각 조절할 수 있습니다.

### 3. 스크린샷과 로컬 문자 인식

<p align="center"><img src="docs/images/screenshot-entry.png" width="720" alt="원본 이미지와 편집 가능한 인식 텍스트가 함께 있는 저장된 스크린샷 항목"></p>

**Alt+W** 또는 스크린샷 버튼을 누르고 끌어서 영역을 선택하세요. 저장한 스크린샷은 선택한 그룹의 이미지 항목이 됩니다. 항목을 열어 미리보기, 복사, PNG 저장 또는 **문자 인식**을 실행할 수 있습니다. 원본 이미지를 유지하면서 인식한 텍스트를 편집하고 검색할 수 있습니다.

영역 선택 후 도구 모음에서 세 가지 동작을 따로 선택할 수 있습니다.

| 동작 | 결과 |
| --- | --- |
| 스크린샷 저장 | 이미지 항목을 저장합니다. Enter로 이 동작을 선택할 수 있습니다. |
| 텍스트 추출 | 로컬 OCR을 실행하고 임시 텍스트를 표시합니다. 항목을 저장하거나 자동으로 복사하지 않습니다. |
| 추출 후 번역 | 로컬 OCR을 실행한 뒤 인식한 텍스트를 선택한 번역 제공업체로 보냅니다. 스크린샷 자체는 업로드하지 않습니다. |

<p align="center"><img src="docs/images/screenshot-text.png" width="480" alt="1.2.2에서 사용자가 직접 텍스트를 복사할 수 있는 임시 OCR 결과"></p>

다시 끌면 영역을 재선택하며, **Esc** 또는 오른쪽 클릭으로 취소합니다. 임시 결과에서는 직접 복사하거나 번역을 다시 시도할 수 있고, 번역에 실패해도 원문이 유지됩니다. OCR은 문자를 인식하는 단계이며 자동으로 번역하지 않습니다. [스크린샷 사용 흐름](docs/SCREENSHOTS.md) · [OCR 지원 범위 및 한계](docs/LOCAL_OCR.md).

**1.2.3:** 임시 OCR 및 번역 결과에서 **원문 저장**, **번역 저장**, **둘 다 저장**을 선택하고 그룹을 지정할 수 있습니다. 초기 선택은 현재 그룹입니다. 둘 다 저장하면 원문과 번역을 구분한 하나의 텍스트 항목을 만듭니다. 명시적으로 클릭할 때만 저장하며 클립보드를 바꾸거나 스크린샷을 함께 저장하지 않습니다. 번역 실패 시에도 원문을 저장할 수 있으며 저장 실패 시 결과를 유지해 재시도할 수 있습니다. 중복 텍스트는 기존 항목을 재사용하고 선택한 그룹으로 이동합니다.

### 4. 선택한 텍스트 작업과 번역

<p align="center"><img src="docs/images/selection-actions.png" width="480" alt="복사와 번역 버튼이 각각 표시되는 1.2.2 텍스트 선택 말풍선"></p>

**설정 > 캡처 및 번역**에서 텍스트 선택 말풍선을 켠 뒤 다른 앱에서 텍스트를 선택하세요. **복사**는 선택한 내용을 도크의 현재 그룹에 저장하며, **번역**은 항목을 추가하지 않고 번역 결과를 표시합니다.

**복사 및 번역**을 선택하면 두 버튼이 함께 표시됩니다. 복사한 뒤에도 말풍선이 닫히기 전까지 같은 선택 내용을 번역할 수 있습니다. 번역에 실패해도 원문은 유지됩니다.

**1.2.3:** 설정에서 번역 대상 언어를 화면 언어와 별도로 선택할 수 있습니다. 새 설치 및 업그레이드의 기본값은 **화면 언어 따르기**입니다. 선택 텍스트, 스크린샷 번역과 번역 테스트에 같은 설정을 적용합니다. 결과 창에서 실제 대상 언어를 확인하고 보관된 원문을 다른 언어로 다시 번역할 수 있습니다. 이 임시 선택은 현재 결과에만 적용되며 전역 설정을 바꾸지 않습니다. 지원 언어는 제공업체나 설치된 모델에 따라 다릅니다. 지원하지 않는 언어 쌍은 오류로 알리며 제공업체를 자동으로 바꾸거나 오프라인 텍스트를 업로드하지 않습니다.

| 제공업체 | 설정 및 이용 조건 |
| --- | --- |
| Bing (중국), Google, Lingva | 키가 필요하지 않습니다. 서비스 이용 가능 여부는 보장되지 않습니다. 새 설치에서는 Google이 기본값이며, 기존 설정은 유지됩니다. |
| Baidu, Alibaba Cloud, DeepL | 본인의 인증 정보를 입력해야 합니다. 무료 할당량과 요금은 제공업체 및 계정에 따라 다릅니다. Alibaba Cloud는 기계 번역 서비스 활성화와 `alimt:TranslateGeneral` 권한이 필요합니다. |
| 로컬 오프라인 | 선택 구성 요소인 로컬 엔진을 설치합니다. 계정이나 API 요금 없이 루프백 서비스를 사용합니다. |

클라우드 번역은 요청한 텍스트만 선택한 제공업체로 보내며, 제공업체를 자동으로 전환하지 않습니다. OCR은 이미지를 업로드하지 않습니다. 제공업체 인증 정보는 로컬 `settings.json`에 **평문으로** 저장됩니다. 입력 필드에서 문자를 가리는 것은 암호화가 아닙니다.

### 5. 앱 안에서 선택 구성 요소 설치하기

<p align="center"><img src="docs/images/component-setup.png" width="720" alt="OCR과 오프라인 번역의 설치 및 복구 버튼이 있는 선택 구성 요소 설정"></p>

*1.2.2를 새로 설치했을 때의 구성 요소 설정입니다. OCR과 오프라인 번역은 설치되어 있지 않습니다. 앱 안의 이 버튼으로 설치할 수 있으며 터미널 명령은 필요하지 않습니다.*

1. **설정 > 로컬 구성 요소**를 여세요.
2. OCR을 처음 사용하기 전에 **문자 인식 (중국어 / 영어)** 아래에서 **설치 / 복구**를 선택하세요. 1.2.3에는 OCR과 로컬 번역 엔진 및 모델이 사전 설치되지 않습니다. 명시적으로 설치할 때 필요한 파일을 다운로드하고 검증하며 네이티브 런타임도 확인합니다.
3. 로컬 번역을 사용하려면 **오프라인 번역 (중국어 / 영어)** 아래의 **설치 / 복구**를 선택하세요. 첫 다운로드 중에는 설정 창을 열어 두고, 약 **1 GB의 여유 디스크 공간**과 **2 GB의 사용 가능한 메모리**를 확보하세요.
4. Microsoft 설치 프로그램이 나타나면 안내를 따르세요. **다시 시작 필요**가 표시되면 Windows를 다시 시작한 뒤 재시도하세요. 앱의 설치를 취소해도 이미 시작한 Windows 런타임 설치는 되돌려지지 않습니다.
5. 번역 엔진으로 **로컬 오프라인 (Argos / LibreTranslate)**을 선택하세요. `http://127.0.0.1:5000`을 유지하고 **번역 테스트**를 실행하세요. 서비스는 필요할 때 시작되며, **서비스 시작**과 **서비스 중지**도 사용할 수 있습니다.

최초 설치에는 관련 NuGet, GitHub, Python, 패키지, 모델 및 Microsoft 다운로드 서버에 연결할 수 있는 인터넷 환경이 필요합니다. 다운로드가 실패하면 다시 시도할 수 있으며, 유효한 캐시 파일은 재사용됩니다. 설치 후에는 OCR과 로컬 번역을 오프라인으로 사용할 수 있습니다. 번역 서비스는 앱을 닫아도 직접 중지할 때까지 계속 실행됩니다.

**지원 언어:** OCR은 인쇄된 영어와 중국어 간체를 지원합니다. 선택적으로 다운로드하는 번역 모델은 **영어 ↔ 중국어 간체**를 지원합니다. 앱의 **20개 화면 언어**가 OCR이나 오프라인 번역도 20개 언어를 지원한다는 뜻은 아닙니다. 모델이 없더라도 클라우드 번역으로 전환하지 않습니다. [오프라인 설치 및 문제 해결](docs/OFFLINE_TRANSLATION.md).

### 6. 업데이트 확인

<p align="center"><img src="docs/images/update-check.png" width="720" alt="가상의 새 버전과 가려진 설치 경로가 표시된 업데이트 창"></p>

*표시된 릴리스는 시뮬레이션이며 설치 경로는 가렸습니다. 이 이미지가 실제 새 버전의 배포를 알리는 것은 아닙니다.*

트레이 메뉴 또는 **설정 > 정보**의 **업데이트 확인**을 사용하세요. 확인만으로는 다운로드하거나 설치하지 않습니다. 다운로드 시 SHA-256과 패키지 내용을 검증하며, **다시 시작하고 업그레이드**하려면 별도로 확인해야 합니다. 업데이트 프로그램은 기존 경로의 관리 대상 앱 파일을 교체하고, 사용자 데이터와 설치된 구성 요소를 보존하며, 시작에 실패할 경우를 위한 복구 정보를 유지합니다.

정리된 패키지의 루트에는 `KeeStashDock.exe`, `StartHere.md`, `update-manifest.json` 세 파일이 있습니다. 안내 문서는 `Docs`, 라이선스 고지는 `Licenses`에 있으며, 언어와 선택 구성 요소는 각각 전용 폴더에 보관됩니다. 전체 패키지를 함께 유지하세요. [업데이트 및 복구](docs/UPDATING.md).

## 데이터, 백업, 업그레이드

**1.2.3:** 설정에서 마지막 성공, 최근 확인, 다음 예정 확인, 상태, 백업 위치와 스냅샷 수를 볼 수 있습니다. **지금 백업**, 폴더 열기, 안전한 복원 절차를 사용하는 목록 복원을 지원합니다. 주기는 **15／30／60분**, 6／12／24／48시간, 7일이며 기본값은 **24시간**입니다. 기존 사용자 지정 주기와 보관 수를 유지합니다. 15분 간격으로 스냅샷 7개를 보관하면 가장 오래된 것부터 최신까지 **90분**만 포함하므로 저장 공간 예상치와 함께 보관 수를 선택하세요. 데이터베이스에 변경이 없어도 정기 백업마다 전체 스냅샷을 만듭니다. 간격이 짧으면 보관 기록도 더 빨리 교체됩니다. 백업 범위는 저장된 이미지를 포함한 항목 데이터베이스이며 **모든 설정, 구성 요소, 배경을 포함하지 않습니다**. 자동 정리는 수동 내보내기나 복구 사본을 삭제하지 않습니다.

<p align="center"><img src="docs/images/backup-settings.png" width="720" alt="24시간마다 자동 백업이 켜져 있고 경로를 가린 데이터 설정"></p>

항목, 이미지, 인식한 텍스트, 백업은 로컬에 저장됩니다. 휴대용 데이터는 일반적으로 실행 파일 옆의 `Data` 폴더에 저장됩니다. 해당 폴더에 쓸 수 없으면 `%AppData%\KeeStashDock`을 사용하며, 설정에서 대체 저장 경로를 알려 줍니다. 앱을 통해 설치한 구성 요소는 일반적으로 `%LOCALAPPDATA%\KeeStashDock`을 사용하며, 사용자 자료와 별도로 보관됩니다.

**설정 > 백업 및 데이터**에서 백업을 내보내거나 가져오고 정기 백업을 설정하세요. **1.2.1에서 처음 업그레이드할 때는 수동으로** 진행해야 합니다.

1. 백업을 내보낸 뒤 트레이 메뉴에서 앱을 종료하세요.
2. 새 ZIP을 별도의 폴더에 푸세요. 앱이 종료된 상태에서 **현재 사용 중인 데이터 폴더 전체**를 새 설치의 `Data` 폴더로 복사하세요. 설정에 `%AppData%` 대체 경로가 표시되면 그 폴더를 원본으로 사용하세요.
3. 기존 설치와 백업을 보관하세요. 새 버전을 실행하고 항목을 확인한 뒤 오래된 사본을 제거하세요. 이전 버전으로 돌아갈 수 있도록 업그레이드 전 백업을 유지하세요. 이전 데이터베이스 스키마와 새 스키마는 서로 교환해 사용할 수 없습니다.
4. **Windows 시작 시 실행**이 켜져 있고 새 폴더로 옮겼다면, 새 앱의 설정에서 이 옵션을 껐다가 다시 켜세요. 새 실행 파일 경로가 등록됩니다. 그렇지 않으면 다음 로그인 시 이전 앱이 실행될 수 있습니다.

**1.2.2**에서는 **업데이트 확인**을 사용하거나 위 절차로 수동 업데이트할 수 있습니다. **1.2.3 후보 버전(r1–r4)**은 정식 버전과 숫자 버전이 같으므로 수동 교체가 필요합니다. 사용 중인 데이터 폴더 전체와 백업을 보관하고, 이전 프로세스를 완전히 종료한 뒤 새 앱을 실행하세요.

이슈에 개인 `Data`, 인증 정보, 개인 백업 또는 로그를 첨부하지 마세요. [지원 및 민감 정보를 제거한 보고](SUPPORT.md), [업그레이드 복구](docs/UPDATING.md), [보안 정책](SECURITY.md)을 참고하세요.
