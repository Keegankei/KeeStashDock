## 快速开始

**[下载最新已发布版本](https://github.com/Keegankei/KeeStashDock/releases/latest)**

1.3.0 正式发布时将在 **Assets** 中提供 `KeeStashDock-1.3.0-win-x64.zip` 和 `KeeStashDock-1.3.0-win-x64.zip.sha256`。这些是计划使用的发布文件名，不代表文件已经可供下载。

1. 在发布页的 **Assets** 中下载应用 ZIP；GitHub 的 **Source code** 压缩包面向开发者。
2. 将完整软件包解压到可写文件夹，运行 `KeeStashDock.exe`。请保留所有附带文件夹。
3. 按 **Alt+Q** 显示快速面板。输入文本片段后按 **Enter** 保存；点击卡片即可复制。
4. 从面板或系统托盘打开**设置**，选择语言、主题和可选组件。

Windows x64 软件包已包含 .NET，无需另外安装。主要支持 Windows 11，并尽力兼容 Windows 10 22H2。OCR 和离线翻译可能需要 Microsoft Visual C++ 运行库，可通过应用内组件安装流程安装。已验证范围与待完成检查见 [1.3.0 验证记录](docs/releases/1.3.0.md)。

<details>
<summary>校验下载的 ZIP</summary>

在下载文件夹中运行以下命令，将结果与附带的 `.sha256` 文件比较：

```powershell
Get-FileHash .\KeeStashDock-1.3.0-win-x64.zip -Algorithm SHA256
```

校验和用于检查文件完整性，不是发布者签名。当前软件包未签名。

</details>

**全新安装默认设置 · 1.3.0：**界面为英文；**Alt+Q** 打开面板，**Alt+W** 截图。不预装 OCR 和本地翻译。升级会保留已有设置。

划词气泡默认开启，动作为**仅复制**，翻译引擎为 **Google**；气泡采用默认样式。开机启动、自动收集剪贴板和直接粘贴默认关闭。贴边自动收纳默认开启，收起延时 **2 秒**、展开延时 **0.1 秒**。外观跟随系统，使用**标准**模式；空间模式的检视方式预设为**按住右键拖动**。面板文字配色自动，控件不透明度 **90%**；无背景图，蒙层不透明度 **20%**，毛玻璃关闭，预设半径 **4 px**。定时自动备份默认开启，每 **24 小时**运行。

文字大小默认为 **100%**，设置页表面不透明度为 **100%**；设置页毛玻璃默认**关闭**。随附主题供按需选择，不会自动应用。

## 功能介绍

### 1.3.0 新增功能

| 功能 | 使用方式 |
| --- | --- |
| 快捷面板搜索 | 面板激活时按 **Ctrl+F**，搜索标题及已保存文字，包括已有 OCR 结果；可组合分组、标签和文本／图片／模板筛选。每页加载 50 条，支持继续加载。按 **Enter** 复制选中结果，按 **Esc** 返回收集，保留输入草稿。 |
| 批量整理 | 在工作台选择条目后，批量移动分组、添加／移除标签、置顶／取消置顶、移入回收站或恢复。**Ctrl+A 仅选择当前已加载结果。** 整批统一提交，冲突时不修改任何条目。移入回收站后，条目未发生后续变化时可撤销。 |
| 文本模板 | 主动将文本条目标记为模板，使用 `{{date}}`、`{{time}}` 及 `{{name}}` 等命名变量，填写、预览后再复制。原模板保持不变，不执行脚本或表达式。含模板的分组包使用 v3 格式。 |
| 完整主题方案 | 预览并应用覆盖各类应用面板的协调配色和背景，将明暗两套方案及素材作为一个主题 ZIP 导入或导出。主题与标准／空间模式独立；取消预览会恢复原外观。 |
| 全局文字大小 | 在**设置 > 外观 > 文字大小**中选择 **90%–150%**，统一调整快捷面板、工作台、设置及其他应用文字；**100%** 恢复原始大小。 |
| 工作台外观 | 导航、条目列表和编辑区采用与设置页一致的设计。深色模式下的列表和备份行使用协调背景与清晰文字。 |
| 紧凑气泡 | 原文与结果的复制按钮内联显示，目标语言、分组和保存操作布局更紧凑。默认样式与 Wisteria Atelier 使用相同控件和协调配色。 |
| 不透明度与毛玻璃 | 设置页表面不透明度可独立调节为 **10%–100%**。可选设置页毛玻璃以 **1–18 px** 柔化背景图，文字保持清晰。气泡样式和透明度可独立调整。 |

新安装仍默认英文、跟随系统主题、标准模式且无背景图片。升级不会自动套用插画主题，也不会重置已保存偏好。

**设置导航：**按**常规、截取与翻译、外观、本地组件、备份与数据、关于**分类。相关选项仅在需要时显示，隐藏不会重置已保存的选择。

在**截取与翻译**中，可独立开关结果窗口的目标语言选择器与保存到分组面板。两项默认开启，在 OCR 或翻译完成后显示；关闭后仍可查看和复制结果。

在**备份与数据**中选择备份文件夹，在**本地组件**中分别选择 OCR 和离线翻译文件夹。更改位置**不会移动已有文件**；新组件文件夹为空时需重新安装。**关于**中只读展示当前应用数据位置，迁移资料库请使用导出和导入。

下方 **1.3.0** 工作台、主题和气泡预览使用虚构内容，由实际 WPF 控件离屏渲染。其余 **1.2.3** 截图和 GIF 展示已有操作流程。空间检视动图使用模拟指针，更新预览使用模拟版本。安装路径和数据路径已遮蔽，不包含个人桌面或剪贴板内容。[图片来源与生成方式](docs/images/README.md)。

- **固定透视：**保持稳定的倾斜视角，附近卡片仍响应指针。

### 3. 截图与本地文字识别

*本节截图流程图片展示 1.2.3。*

<p align="center"><img src="docs/images/screenshot-entry.png" width="720" alt="已保存的截图条目，包含原图和可编辑的识别文字"></p>

按 **Alt+W** 或点击截图按钮，拖动选择区域。保存的截图会成为当前所选分组中的图片条目。打开条目可预览、复制、另存为 PNG，或**识别文字**。保留原图的同时，可以编辑和搜索识别结果。

选区完成后，工具栏提供三项独立操作：

| 操作 | 结果 |
| --- | --- |
| 保存截图 | 保存为图片条目。按 Enter 执行此操作。 |
| 提取文字 | 运行本地 OCR 并显示临时文字，不保存条目，也不自动复制。 |
| 提取并翻译 | 先运行本地 OCR，再将识别文字交给所选翻译服务。截图本身不会上传。 |

<p align="center"><img src="docs/images/screenshot-text.png" width="480" alt="1.2.3的临时 OCR 结果，提供明确的文字复制操作"></p>

再次拖动可以重新选择区域；按 **Esc** 或右键取消。临时结果支持主动复制，翻译失败后保留原文，并可重试翻译。OCR 仅负责识别，不会自动翻译。[截图使用流程](docs/SCREENSHOTS.md) · [OCR 支持范围与限制](docs/LOCAL_OCR.md)。

临时 OCR 和翻译结果提供**保存原文**、**保存译文**、**同时保存**及默认使用当前分组的选择器。同时保存会生成一条明确区分原文与译文的文本条目。仅在主动点击后保存，不改变剪贴板，也不附带保存截图。翻译失败仍可保存原文；保存失败保留结果以便重试。重复文字沿用已有条目并放入所选分组。

*两张 1.3.0 预览均启用了可选的“复制和翻译”模式；全新安装仍默认为“仅复制”。*

在**设置 > 截取与翻译**中启用划词气泡，然后在其他应用中选择文字。**复制**会将所选文字保存到面板当前分组；**翻译**显示译文，不添加条目。

选择**复制和翻译**，即可同时显示两个按钮。复制后，在气泡关闭前仍可翻译同一段选中文字。翻译失败时会保留原文。

可在设置中独立于界面语言选择翻译目标语言。全新安装默认**跟随界面语言**，升级保留原有选择。划词翻译、截图翻译和测试翻译共用此设置。结果窗口显示实际目标语言，也可仅对本次保留原文更换翻译语言，不修改设置。可用语言取决于翻译提供方或已安装离线模型；不支持的语言对会报错，不会切换提供方或上传离线文字。

### 5. 在应用内安装可选组件

<p align="center"><img src="docs/images/component-setup.png" width="720" alt="可选组件设置，提供 OCR 和离线翻译的安装及修复按钮"></p>

<details>
<summary>组件安装文件夹</summary>

<p align="center"><img src="docs/images/component-folders.png" width="720" alt="1.2.3 英文界面的组件文件夹选项；路径已遮蔽。"></p>

1. 打开**设置 > 本地组件**。
2. 首次使用 OCR 前，在**文字识别（中文 / 英文）**下选择**安装 / 修复**。标准软件包不预装 OCR 或本地翻译引擎及模型；主动安装时才下载并验证所需文件，同时检查本机运行库。
3. 本地翻译请在**离线翻译（中文 / 英文）**下选择**安装 / 修复**。首次下载期间保持设置窗口打开，并预留约 **1 GB 磁盘空间**和 **2 GB 可用内存**。
4. 如出现 Microsoft 安装程序，按提示操作。如提示**需要重启**，重启 Windows 后重试。取消应用组件安装不会撤销已开始的 Windows 运行库安装。
5. 将翻译引擎设为**本地离线（Argos / LibreTranslate）**，保留 `http://127.0.0.1:5000`，然后使用**测试翻译**。服务会在需要时启动，也可手动选择**启动服务**和**停止服务**。

首次设置需要访问相关 NuGet、GitHub、Python、软件包、模型及 Microsoft 下载站点。下载失败后可重试，已验证的缓存文件会被复用。安装完成后，OCR 和本地翻译可以离线运行。翻译服务在应用关闭后仍会运行，直到主动停止。

**语言支持：**OCR 支持打印体英语和简体中文。可选下载的翻译模型支持**英语 ↔ 简体中文**。应用的 **20 种界面语言**不代表 OCR 或离线翻译支持 20 种语言。缺少模型时不会自动切换到云翻译。[离线安装与故障排查](docs/OFFLINE_TRANSLATION.md)。

### 6. 检查更新

<p align="center"><img src="docs/images/update-check.png" width="720" alt="更新窗口展示模拟的新版本，安装路径已遮蔽"></p>

*图中的版本为模拟示例，安装路径已遮蔽，不表示已有该版本可供下载。*

在托盘菜单或**设置 > 关于**中选择**检查更新**。检查不会自动下载或安装。下载时会验证 SHA-256 和软件包内容；**重启并升级**需要单独确认。更新程序在原有路径替换受管理的应用文件，保留用户数据和已安装组件，并在启动失败时保留恢复信息。

整理后的软件包根目录只有三个文件：`KeeStashDock.exe`、`StartHere.md` 和 `update-manifest.json`。使用说明位于 `Docs`，版权声明位于 `Licenses`，语言与可选组件各有专用文件夹。请完整保留软件包。[更新与恢复](docs/UPDATING.md)。

## 数据、备份与升级

**1.3.0 数据库兼容性：**应用会将资料库升级到 **schema 5**。修改旧数据库前，会创建并验证一致的安全备份，包含已提交的 WAL 数据；备份失败时停止迁移。**1.2.3 及更早版本无法打开 schema 5。** 恢复旧程序文件不会降级资料库。请保留完整当前数据文件夹和升级前备份；如需回退，应使用兼容备份的独立副本，不要覆盖较新数据。

主题位于可执行文件旁的 `theme/`：`builtin/` 为应用管理的资源，`custom/` 为用户导入的主题。更新保留 `theme/custom/`。**数据库备份不包含主题。** 请使用设置中的主题导出功能，单独迁移或备份完整明暗外观及其图片。

设置中显示最近成功备份、最近检查、下次计划检查、运行状态、备份位置和快照数量。可**立即备份**、打开文件夹，或从列表经安全恢复流程还原快照。周期新增 **15／30／60 分钟**，同时保留 6／12／24／48 小时及 7 天，默认仍为 **24 小时**。保留已有自定义周期和保留数量。每 15 分钟保留 7 份快照时，最早至最新仅覆盖 **90 分钟**，请结合存储估算选择保留数量。每次计划备份都会创建完整快照，即使数据库未变化；短周期会更快轮换历史。这些备份覆盖条目数据库及其中的图片，**不包括全部设置、组件或背景图**。自动轮换不会删除手动导出或恢复副本。

条目、图片、识别文字和备份均保存在本地。便携数据通常位于可执行文件旁的 `Data` 文件夹。如该位置不可写，应用会改用 `%AppData%\KeeStashDock`，并在设置中提示。通过应用安装的组件通常位于 `%LOCALAPPDATA%\KeeStashDock`，与内容收藏分开存放。

在**设置 > 备份与数据**中导出/导入备份并配置定时备份。从 **1.2.1 首次升级需要手动进行**：

1. 导出备份，然后通过托盘菜单退出应用。
2. 将新 ZIP 解压到独立文件夹。在应用关闭时，将**当前使用的完整数据文件夹**复制到新安装的 `Data` 文件夹。如果设置显示使用 `%AppData%` 回退位置，请以该文件夹为来源。
3. 保留原安装和备份，启动新版本并确认条目完整后再清理旧副本。保留升级前的备份以便回退；不同版本的数据库结构不能随意互换。
4. 如果原来开启了**开机启动**，且此次迁移到新目录，请在新版设置中先关闭再开启该选项，以登记新的程序路径；否则下次登录 Windows 时可能启动旧版。

从 **1.2.2** 起可使用**检查更新**，也可按上述步骤手动升级。**1.3.0 候选构建（包括 r1–r5）**与正式版使用相同数字版本，需手动替换。请保留完整当前数据文件夹与备份，并退出旧进程后再启动新副本。

请勿在问题报告中附上个人 `Data`、凭据、私密备份或日志。参阅[支持与脱敏报告](SUPPORT.md)、[升级恢复](docs/UPDATING.md)和[安全政策](SECURITY.md)。
