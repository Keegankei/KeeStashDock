## 快速開始

**[下載 v1.3.0](https://github.com/Keegankei/KeeStashDock/releases/tag/v1.3.0)**

**發布附件：**[KeeStashDock-1.3.0-win-x64.zip](https://github.com/Keegankei/KeeStashDock/releases/download/v1.3.0/KeeStashDock-1.3.0-win-x64.zip) · [SHA-256 校驗檔案](https://github.com/Keegankei/KeeStashDock/releases/download/v1.3.0/KeeStashDock-1.3.0-win-x64.zip.sha256)

1. 在發布頁的 **Assets** 中下載應用程式 ZIP；GitHub 的 **Source code** 壓縮檔供開發者使用。
2. 將完整套件解壓縮至可寫入的資料夾，執行 `KeeStashDock.exe`。請保留所有隨附資料夾。
3. 按 **Alt+Q** 顯示快速面板。輸入文字片段後按 **Enter** 儲存；點選卡片即可複製。
4. 從面板或系統匣開啟**設定**，選擇語言、佈景主題與選用元件。

Windows x64 套件已包含 .NET，無需另外安裝。主要支援 Windows 11，並盡力相容 Windows 10 22H2。OCR 與離線翻譯可能需要 Microsoft Visual C++ 執行階段，可透過應用程式內的元件安裝流程安裝。已驗證範圍與平台限制見 [1.3.0 驗證紀錄](docs/releases/1.3.0.md)。

**全新安裝預設值 · 1.3.0：**介面為英文；**Alt+Q** 開啟面板，**Alt+W** 擷取螢幕。不預先安裝 OCR 與本機翻譯。升級會保留既有設定。

選取文字泡泡預設開啟，動作為**僅複製**，翻譯引擎為 **Google**；泡泡採用預設樣式。開機啟動、自動收集剪貼簿與直接貼上預設關閉。貼邊自動收納預設開啟，收起延遲 **2 秒**、展開延遲 **0.1 秒**。外觀跟隨系統，使用**經典**模式；浮境模式的檢視方式預設為**按住右鍵拖曳**。面板文字配色自動，控制項不透明度 **90%**；無背景圖，遮罩不透明度 **20%**，毛玻璃關閉，預設半徑 **4 px**。定時自動備份預設開啟，每 **24 小時**執行。

文字大小預設為 **100%**，設定頁表面不透明度為 **100%**；設定頁毛玻璃預設**關閉**。隨附主題供按需選用，不會自動套用。

## 功能介紹

### 1.3.0 新增功能

| 功能 | 使用方式 |
| --- | --- |
| 快捷面板搜尋 | 面板啟用時按 **Ctrl+F**，搜尋標題及已儲存的文字，包括既有 OCR 結果；可組合群組、標籤與文字／圖片／範本篩選。每頁載入 50 個項目，支援繼續載入。按 **Enter** 複製選取結果，按 **Esc** 返回收集，並保留輸入草稿。 |
| 批次整理 | 在工作台選取項目後，可批次移動群組、新增／移除標籤、置頂／取消置頂、移至資源回收筒或還原。**Ctrl+A 僅選取目前已載入的結果。** 整批一次提交，發生衝突時不變更任何項目。移至資源回收筒後，若項目未再變更便可復原操作。 |
| 文字範本 | 主動將文字項目標記為範本，使用 `{{date}}`、`{{time}}` 及 `{{name}}` 等命名變數，填寫並預覽後再複製。原範本保持不變，不執行指令碼或運算式。含範本的群組套件使用 v3 格式。 |
| 完整佈景主題 | 預覽並套用涵蓋各類應用程式面板的協調配色與背景，將淺色與深色兩套外觀及素材匯入或匯出為一個主題 ZIP。主題與經典／浮境模式各自獨立；取消預覽會還原原有外觀。 |
| 全域文字大小 | 在**設定 > 外觀 > 文字大小**中選擇 **90%–150%**，統一調整快捷面板、工作台、設定及其他應用程式文字；**100%** 還原原始大小。 |
| 工作台外觀 | 導覽、項目清單與編輯區採用與設定頁一致的設計。深色模式的清單與備份列使用協調背景及清晰文字。 |
| 緊湊泡泡 | 原文與結果的複製按鈕內嵌顯示，目標語言、群組與儲存操作配置更緊湊。預設樣式與 Wisteria Atelier 使用相同控制項及協調配色。 |
| 不透明度與毛玻璃 | 設定頁表面不透明度可獨立調整為 **10%–100%**。選用設定頁毛玻璃以 **1–18 px** 柔化背景圖，文字保持清晰。泡泡樣式與透明度可獨立調整。 |

全新安裝仍預設使用英文、跟隨系統主題、經典模式且沒有背景圖片。升級不會自動套用插畫主題，也不會重設已儲存的偏好。

**設定導覽：**依**一般、擷取與翻譯、外觀、本機元件、備份與資料、關於**分類。相關選項僅在需要時顯示，隱藏不會重設已儲存的選擇。

在**擷取與翻譯**中，可獨立開關結果視窗的目標語言選擇器與儲存至群組面板。兩項預設開啟，在 OCR 或翻譯完成後顯示；關閉後仍可查看及複製結果。

在**備份與資料**中選擇備份資料夾，在**本機元件**中分別選擇 OCR 與離線翻譯資料夾。變更位置**不會移動現有檔案**；新的元件資料夾為空時需重新安裝。**關於**中唯讀顯示目前的應用程式資料位置，移轉資料庫請使用匯出及匯入。

下方 **1.3.0** 工作台、主題與泡泡預覽使用虛構內容，由實際 WPF 控制項離屏繪製。其餘 **1.2.3** 擷取畫面與 GIF 展示現有操作流程。空間檢視動圖使用模擬指標，更新預覽使用模擬版本。安裝路徑與資料路徑已遮蔽，不包含個人桌面或剪貼簿內容。[圖片來源與產生方式](docs/images/README.md)。

### 1. 收集、搜尋與整理

<p align="center"><img src="docs/images/1.3.0/workbench-light.png" width="900" alt="1.3.0 工作台展示搜尋、多選與範本編輯器，使用選用的 Wisteria Atelier 淺色主題"></p>

*1.3.0 · 工作台與文字範本編輯器 · 選用 Wisteria Atelier 淺色主題。*

使用快速面板隨手收集內容，在**工作台**管理收藏。點選面板的展開按鈕或使用系統匣選單開啟工作台。

| 工具 | 可以完成的操作 |
| --- | --- |
| 快速輸入與搜尋 | 按 Enter 儲存，Alt+Enter 或 Shift+Enter 換行。在快捷面板按 Ctrl+F 搜尋；快捷面板與工作台皆支援群組、標籤與類型篩選。 |
| 拖入面板 | 拖入文字即可儲存，拖入檔案或資料夾則儲存其路徑。點選路徑卡片開啟目標；以右鍵選擇**複製**可複製路徑。不會匯入檔案內容。 |
| 群組、標籤與釘選 | 將相關項目放在一起，編輯標題、內文與標籤，並釘選常用內容。 |
| 有效期限與資源回收筒 | 可選永不過期、一天、七天或閱後即焚；過期與刪除的項目進入資源回收筒，可以還原。資源回收筒中的項目預設於 30 天後永久刪除。 |
| 桌面便箋 | 將文字或路徑卡片拖出面板，在本次執行期間作為獨立桌面便箋顯示。結束應用程式會關閉這些便箋，但已儲存的項目仍保留在收藏中。圖片卡片仍作為圖片項目使用。 |
| QR 碼 | 以右鍵點選文字卡片，將最多 1,800 個字元展示為 QR 碼。 |
| 文字工具 | 使用工作台的轉換選單進行大小寫轉換、空白清理、JSON 格式化、URL 編解碼與 Base64 處理。 |
| 群組匯入／匯出 | 分享 `.ksdgrp` 套件，或載入 Git、Docker、Shell 等工具的命令預設集。含範本的群組套件採用格式 3，需要 1.3.0 或更新版本；仍可匯入格式 1 與 2。 |
| 剪貼簿歷程 | 可選擇自動收集複製的**文字**；忽略空白與過大的文字，不重複新增相同內容。預設關閉。 |
| 直接貼上 | 能夠安全確認目標視窗時，可選擇將複製的文字項目貼到先前的應用程式。預設關閉。 |

*白色指標展示靠近卡片時的回饋；橘色指標表示按住拖曳檢視。這是效果示範動圖，並非影格率測試。*

- **固定透視：**保持穩定的傾斜視角，附近卡片仍回應指標。
- **拖曳檢視：**在卡片內文或面板背景上按住**滑鼠右鍵**拖曳，放開後保留角度。未拖曳的右鍵點選仍開啟卡片選單。設定中也可選擇中鍵或自訂滑鼠按鍵與修飾鍵組合。
- **精簡列：**將面板收合為六個操作：最小化、展開/收合、鎖定、螢幕擷取、工作台與設定。展開時恢復先前的面板大小。
- **桌面邊緣隱藏：**預設開啟。將面板拖曳到螢幕任一邊緣，再移開滑鼠。邊緣會保留一個小把手，停留其上或點選即可恢復。鎖定面板可使其保持顯示。

兩種模式皆可拖曳展開面板的邊緣或四角調整大小，重新啟動後還原之前的尺寸；六按鈕緊湊列維持固定大小。

支援淺色、深色與跟隨系統佈景主題，可設定自訂背景、透明度與磨砂效果。系統高對比與減少動畫的偏好會啟用靜態替代顯示。[深色預覽](docs/images/floating-panel-dark.png) · [固定視角預覽](docs/images/floating-panel-fixed.png)。

設定也提供面板文字配色、自訂文字顏色與自動對比度，以及獨立的選取文字泡泡樣式與透明度控制。

### 3. 螢幕擷取與本機文字辨識

*本節擷取流程圖片展示 1.2.3。*

<p align="center"><img src="docs/images/screenshot-entry.png" width="720" alt="已儲存的螢幕擷取項目，包含原圖與可編輯的辨識文字"></p>

按 **Alt+W** 或點選螢幕擷取按鈕，拖曳選取區域。儲存的擷取畫面會成為目前所選群組中的圖片項目。開啟項目可預覽、複製、另存為 PNG，或**辨識文字**。保留原圖的同時，可以編輯與搜尋辨識結果。

完成選取範圍後，工具列提供三項獨立操作：

| 操作 | 結果 |
| --- | --- |
| 儲存螢幕擷取畫面 | 儲存為圖片項目。按 Enter 執行此操作。 |
| 擷取文字 | 執行本機 OCR 並顯示暫存文字，不儲存項目，也不自動複製。 |
| 擷取並翻譯 | 先執行本機 OCR，再將辨識文字交給所選翻譯服務。擷取畫面本身不會上傳。 |

<p align="center"><img src="docs/images/screenshot-text.png" width="480" alt="1.2.3的暫存 OCR 結果，提供明確的文字複製操作"></p>

再次拖曳可以重新選取區域；按 **Esc** 或右鍵取消。暫存結果支援主動複製，翻譯失敗後保留原文，並可重試翻譯。OCR 僅負責辨識，不會自動翻譯。[螢幕擷取使用流程](docs/SCREENSHOTS.md) · [OCR 支援範圍與限制](docs/LOCAL_OCR.md)。

暫存 OCR 與翻譯結果提供**儲存原文**、**儲存譯文**、**同時儲存**及預設使用目前群組的選擇器。同時儲存會建立一筆明確區分原文與譯文的文字項目。僅在主動點選後儲存，不改變剪貼簿，也不附帶儲存截圖。翻譯失敗仍可儲存原文；儲存失敗會保留結果以便重試。重複文字沿用既有項目並移至所選群組。

### 5. 在應用程式內安裝選用元件

<p align="center"><img src="docs/images/component-setup.png" width="720" alt="選用元件設定，提供 OCR 與離線翻譯的安裝及修復按鈕"></p>

*圖中為 1.2.3 全新安裝的元件設定：OCR 和離線翻譯尚未安裝。使用這些應用程式內按鈕即可安裝，無需終端機命令。*

<details>
<summary>元件安裝資料夾</summary>

<p align="center"><img src="docs/images/component-folders.png" width="720" alt="1.2.3 英文介面的元件資料夾選項；路徑已遮蔽。"></p>

*1.2.3 英文介面的元件資料夾選項；路徑已遮蔽。*

</details>

1. 開啟**設定 > 本機元件**。
2. 首次使用 OCR 前，在**文字辨識（中文 / 英文）**下選擇**安裝 / 修復**。標準套件不預先安裝 OCR 或本機翻譯引擎及模型；主動安裝時才下載並驗證所需檔案，同時檢查本機執行階段。
3. 本機翻譯請在**離線翻譯（中文 / 英文）**下選擇**安裝 / 修復**。首次下載期間保持設定視窗開啟，並預留約 **1 GB 磁碟空間**與 **2 GB 可用記憶體**。
4. 如出現 Microsoft 安裝程式，請依提示操作。如提示**需要重新啟動**，重新啟動 Windows 後再試。取消應用程式元件安裝不會復原已開始的 Windows 執行階段安裝。
5. 將翻譯引擎設為**本機離線（Argos / LibreTranslate）**，保留 `http://127.0.0.1:5000`，然後使用**測試翻譯**。服務會在需要時啟動，也可手動選擇**啟動服務**與**停止服務**。

首次設定需要存取相關 NuGet、GitHub、Python、套件、模型與 Microsoft 下載站點。下載失敗後可重試，已驗證的快取檔案會重複使用。安裝完成後，OCR 與本機翻譯可以離線執行。翻譯服務在應用程式關閉後仍會執行，直到主動停止。

**語言支援：**OCR 支援印刷體英語與簡體中文。選用下載的翻譯模型支援**英語 ↔ 簡體中文**。應用程式的 **20 種介面語言**不代表 OCR 或離線翻譯支援 20 種語言。缺少模型時不會自動切換至雲端翻譯。[離線安裝與疑難排解](docs/OFFLINE_TRANSLATION.md)。

## 資料、備份與升級

**1.3.0 資料庫相容性：**應用程式會將資料庫升級到 **schema 5**。修改舊資料庫前，會建立並驗證一致的安全備份，包含已提交的 WAL 資料；備份失敗時停止遷移。**1.2.3 及更早版本無法開啟 schema 5。** 還原舊程式檔案不會降級資料庫。請保留完整目前資料夾與升級前備份；如需回退，應使用相容備份的獨立副本，不要覆寫較新資料。

主題位於執行檔旁的 `theme/`：`builtin/` 存放應用程式管理的資源，`custom/` 存放使用者匯入的主題。更新會保留 `theme/custom/`。**資料庫備份不包含主題。** 請使用設定中的主題匯出功能，另行移轉或備份完整淺色／深色外觀及其圖片。

設定中顯示最近成功備份、最近檢查、下次排程檢查、執行狀態、備份位置與快照數量。可**立即備份**、開啟資料夾，或從清單經安全復原流程還原快照。週期新增 **15／30／60 分鐘**，同時保留 6／12／24／48 小時及 7 天，預設仍為 **24 小時**。保留既有自訂週期與保留數量。每 15 分鐘保留 7 份快照時，最早至最新僅涵蓋 **90 分鐘**，請配合儲存空間估算選擇保留數量。每次排程備份都會建立完整快照，即使資料庫未變更；短週期會更快輪替歷史。備份涵蓋項目資料庫與其中的圖片，**不包括全部設定、元件或背景圖**。自動輪替不會刪除手動匯出或復原副本。

項目、圖片、辨識文字與備份皆儲存在本機。可攜式資料通常位於執行檔旁的 `Data` 資料夾。如果該位置無法寫入，應用程式會改用 `%AppData%\KeeStashDock`，並在設定中提示。透過應用程式安裝的元件通常位於 `%LOCALAPPDATA%\KeeStashDock`，與收藏內容分開儲存。

在**設定 > 備份與資料**中匯出/匯入備份並設定排程備份。從 **1.2.1 首次升級需要手動進行**：

1. 匯出備份，然後透過系統匣選單結束應用程式。
2. 將新 ZIP 解壓縮至獨立資料夾。在應用程式關閉時，將**目前使用的完整資料夾**複製到新安裝的 `Data` 資料夾。如果設定顯示使用 `%AppData%` 備用位置，請以該資料夾為來源。
3. 保留原安裝與備份，啟動新版本並確認項目完整後再清理舊副本。保留升級前的備份以便還原；不同版本的資料庫結構不能任意互換。
4. 如果原本開啟了**開機啟動**，且此次移至新目錄，請在新版設定中先關閉再開啟此選項，以登記新的程式路徑；否則下次登入 Windows 時可能啟動舊版。

從 **1.2.2** 起可使用**檢查更新**，也可依上述步驟手動升級。**1.3.0 候選建置（包括 r1–r5）**與正式版使用相同數字版本，需手動替換。請保留完整目前資料夾與備份，並結束舊處理程序後再啟動新副本。

請勿在問題回報中附上個人 `Data`、憑證、私人備份或記錄。參閱[支援與去識別化報告](SUPPORT.md)、[升級復原](docs/UPDATING.md)及[安全性政策](SECURITY.md)。
