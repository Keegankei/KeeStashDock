# Support

## Where to ask

- Use an issue for a reproducible defect or a narrowly scoped enhancement request.
- Use the repository discussion area, when enabled, for usage questions and broader ideas.
- Follow `SECURITY.md` for vulnerabilities and `CODE_OF_CONDUCT.md` for conduct reports.

Before opening an issue, search existing reports and test the latest tagged release with a clean configuration when practical.

## Information to include

Provide the KeeStashDock version, Windows version, installation or portable path, relevant settings, clear reproduction steps, expected behavior, actual behavior, and sanitized logs. Attach screenshots for layout or rendering problems.

Never upload a real `Data` directory, clipboard database, settings file containing an API key, private backup, or log containing sensitive text. Create a minimal synthetic reproduction instead.

## Scope

Community support is best-effort. Compatibility is targeted at the Windows and architecture combinations documented in the README. Modified binaries, unsupported operating systems, unofficial packaging, and old untagged builds may not be diagnosable.
