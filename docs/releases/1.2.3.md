temporary OCR/translation text; visible backup state and minute scheduling;

The existing symbolic-link fixture is skipped because this execution environment
cannot create the required link. The UI test now explicitly initializes the
language service and dispatcher synchronization context, matching application
startup before exercising asynchronous buttons.

New regressions cover target migration and temporary overrides, failed/duplicate
result saves and stale completion, actual Windows hotkey conflicts, settings
status, minute scheduling including timer callbacks, resume catch-up, backward
clock changes, failure cooldown, maintenance deferral, concurrent backup state,
WAL text/images, atomic export failure, interrupted status and retention. The
Settings scenario uses an isolated real SQLite database and WPF controls to
select 15 minutes, change retention, create a manual snapshot, inspect status
and enable the guarded restore entry without performing a user-data restore.

## Coverage boundaries

Automated tests exercise isolated settings/databases and actual Windows WPF
controls. They do not establish clean-machine UAC behavior, every GPU/DPI/input
device combination, a full interactive update/restart on another computer, or
availability of every remote translation provider. Short backup intervals are
verified with a controllable clock rather than waiting through real days.

Physical disk exhaustion and ACL changes were not manufactured on the user's
machine. Unwritable paths, corrupt sources, cancellation and persisted
interruption fixtures exercise failure handling. Large-library backup latency
has not been benchmarked: a snapshot holds the database operation gate, so
other synchronous queries may briefly wait. Result saves run on a worker and
the application waits for them before an intentional restart or exit.

The README media remains labeled as 1.2.2 footage; it is not evidence that the
new 1.2.3 controls have been manually accepted on every desktop configuration.

## Release handling

Keep the local roadmap excluded from Git and portable packages. Do not include
real user data, credentials, logs, installed optional components or private
paths in release assets. Publish the full ZIP and matching SHA-256 sidecar
together only after accepting the packaged version.
