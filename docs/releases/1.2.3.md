# Version 1.2.3 acceptance record

## Scope

Independent default and temporary translation targets; explicit saving of
temporary OCR/translation text; visible backup state and minute scheduling;
startup shortcut conflict feedback. Database schema v4 and optional component
language coverage remain unchanged.

The second candidate also introduces category navigation and themed switches,
buttons and sliders in Settings; dependent-option visibility; independent result
target/save controls; and configurable database-backup, OCR and offline-runtime
folders. Changing folders preserves existing files. Application data and full
update-recovery locations retain their existing behavior.

## Coverage boundaries

Automated tests exercise isolated settings/databases and actual Windows WPF
controls. They do not establish clean-machine UAC behavior, every GPU/DPI/input
device combination, a full interactive update/restart on another computer, or
availability of every remote translation provider. Short backup intervals are
verified with a controllable clock rather than waiting through real days.

Physical disk exhaustion and ACL changes were not manufactured on the user's
machine. Unwritable paths, corrupt sources, cancellation and persisted
interruption fixtures exercise failure handling. Large-library backup latency
has not been benchmarked: a snapshot holds the database operation gate, so
other synchronous queries may briefly wait. Result saves run on a worker and
the application waits for them before an intentional restart or exit.

The README media remains labeled as 1.2.2 footage; it is not evidence that the
new 1.2.3 controls have been manually accepted on every desktop configuration.
