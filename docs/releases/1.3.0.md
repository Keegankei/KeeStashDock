## Scope

Quick-panel search, workbench batch organization, explicit text templates, complete light/dark themes and safe import/export, global text sizing, workbench/dark-mode presentation updates, compact Default/themed selection and result bubbles, a theme preview dialog aligned with Settings, independent Settings surface opacity, and optional Settings artwork blur. Built-in presets are Sunlit Gallery, Twilight Study, Wisteria Atelier and Wisteria Reverie, in that order, with sixteen portrait/landscape day/night backgrounds.

## Independent backgrounds and mode names · 2026-10-29

The maintainer confirmed normal behavior with the 2026-10-28 corrected package,
including bubble edges, the source background after dragging out a note, and
existing data. The remaining requested changes are Classic / Spatial display
names and independent quick-panel/Settings background selection. Existing mode
settings retain their behavior.

The background category selector does not modify saved preferences. Each area
supports selecting/clearing an image, overlay and blur controls, and returning
to the theme background. Personal images remain outside the theme until the
user explicitly permits including them in an export. Old themes fall back to
their workspace image in Settings; an explicit Settings clear does not erase
the workbench background. Settings-only edits preserve the panel appearance,
exports retain unedited light/dark values, and failed settings writes restore
the previous preferences and report the failure inline.

Query timing fixtures measure database operations on this machine, not full UI frame rate or an operating-system cold cache. Native component setup tests use controlled fixtures rather than fresh model installation or new provider/network acceptance. The symbolic-link fixture may require privileges absent on this host.

The local development plans remain ignored. Each built-in theme includes a
source and license notice. Private production notes and original input images
are excluded from public documentation and the prepared release package.
