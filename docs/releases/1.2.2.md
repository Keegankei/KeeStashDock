# KeeStashDock 1.2.2 candidate acceptance record

Candidate prepared on **2026-10-14**. This is an implementation candidate, not a
published release or a record of maintainer acceptance. The published 1.2.1 ZIP
and checksum are unchanged.

## Implemented scope

- Classic/Floating panel modes, soft outer/card shadows, bounded pointer/press/drag
  feedback, and static high-contrast/reduced-animation behavior.
- Screenshot Save, Extract text, and Extract and translate, with transient OCR,
  explicit copying, component guidance, cancellation and source-text retention.
- Separate Copy/Translate selection-bubble actions, source-session caching,
  clipboard-history suppression and temporary non-activating keyboard shortcuts.
- Explicit GitHub update checks, verified download/staging, same-path managed-file
  replacement, user-data snapshots, process identity checks and health-gated
  rollback/recovery. No silent installation or publisher signing was added.
- Twenty language packs and help text, four READMEs, screenshot/upgrade guidance,
  ownership-manifest tooling and additional CI checks.

## Local validation

The Release build passed with **0 warnings and 0 errors**. The final local
full run had **432 .NET tests: 431 passed, 0 failed and 1 skipped**.
The skipped fixture needs file-symbolic-link creation privileges unavailable to
the validation account; separate PowerShell tests exercised actual NTFS junction
rejection successfully. This run includes the final UI, startup/recovery,
stage-cleanup and concurrent metadata read/write regressions.

All **15 Python offline-helper tests** passed. PowerShell checks passed for
offline process identity, native-runtime setup decisions, cleanup protection,
28 publish-privacy fixtures and update-manifest generation/verification,
including modified/missing/extra files, incorrect versions, invalid ownership
paths, private data and junctions. Initial sandbox-only temporary-file/socket
restrictions were resolved by running the same isolated tests with the required
local access; they were not treated as application defects.

The NuGet advisory check, including transitive desktop dependencies, reported no
known vulnerable packages in its configured feeds on 2026-10-14. This is not an
antivirus scan or a review of every optional native/model asset. The candidate
resolves .NET and Windows Desktop **10.0.13**; upstream runtime notices were
refreshed from that exact NuGet package.

Targeted automated coverage includes:

- Default and persisted panel modes, unchanged visible geometry/44-DIP collapse,
  non-activating click-through shadow ownership, hollow translucent interiors,
  finite motion clocks and hide/close cleanup.
- Screenshot action routing and keyboard behavior, synthetic DPI/negative-coordinate
  crops, transient OCR persistence boundaries, failure/cancellation and explicit
  source copying after translation failure.
- Selection caching across Copy then Translate, duplicate-action prevention,
  stale-result cancellation and clipboard history enabled/disabled.
- Stable release/version selection, invalid/missing metadata, rate limits/network
  errors, checksum mismatch, cancellation and stalled response-body timeout;
  never-installed stage cleanup, update-dialog cancellation and late responses.
- ZIP traversal, reserved paths, links, conflicting/duplicate/undeclared files,
  size limits, ownership hashes, custom-file collisions and preserved components.
- Disposable installation apply/rollback/commit, obsolete managed-file cleanup,
  modified files, injected partial-copy failure, locked files, corrupted recovery
  copies, exact process identities, health nonces, startup/recovery exclusion,
  concurrent journal readers and immediate draft flushing.

Actual WPF controls were rendered using synthetic notes for Classic/Floating
panel, combined selection bubble, transient OCR and simulated update previews. See
[image provenance](../images/README.md). These images do not capture personal
desktop, clipboard, database or provider data.

## Package and publication

The local candidate directory is `publish/KeeStashDock-1.2.2-win-x64`.
The archive is `KeeStashDock-1.2.2-win-x64.zip`, with its matching
`KeeStashDock-1.2.2-win-x64.zip.sha256` sidecar. The package contains a complete
ownership manifest and the upgrade/recovery guide. The release workflow must
regenerate and verify the manifest after every publish, before ZIP creation.

Candidate distribution and source review do not imply a release. A protected
branch PR, successful required Windows CI and maintainer acceptance are required
before tagging and publishing v1.2.2. Do not replace the 1.2.1 assets.

## Remaining acceptance gates

- Maintainer visual/interaction acceptance of shadows and Floating mode with
  actual custom backgrounds, light/dark/high-contrast themes, opacity/frosting,
  card dragging and 100%/150%/200% mixed physical monitors.
- Real screenshot/reselection and OCR workflows on the intended machines,
  external selection focus, non-Latin text, RTL layout and provider credentials.
- A complete real-process upgrade/restart in an isolated Windows session,
  including read-only installation/UAC acceptance and denial, reboot/power loss,
  antivirus interference, startup failure and `%AppData%` fallback. The user's
  normal application was already running on this host; it was not stopped or
  summoned to run a conflicting full application fixture.
- Clean Windows 11 validation and best-effort Windows 10 compatibility. Automated
  fixtures are not certification of every display/GPU/accessibility combination.

The in-app updater begins with 1.2.2. The first upgrade from 1.2.1 is manual;
follow [Updates and recovery](../UPDATING.md) and keep a separate data backup.
