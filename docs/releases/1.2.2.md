# KeeStashDock 1.2.2 acceptance record

Release preparation on **2026-10-17** retains the revision-7 defaults and optional
component layout, fixes selection-listener recovery after screenshots, and
updates the nine-language documentation for 1.2.2. Existing settings retain
their saved preferences and installed optional components remain available.
The maintainer confirmed the update check, card tear-out and screenshot selection
fixes in revision 2, and accepted the basic perspective direction in revision 3.
Remaining physical-device acceptance limits are listed below. Preparing the
release package does not publish a GitHub Release or merge the branch; the
published 1.2.1 ZIP and checksum remain unchanged.

## Implemented scope

- Standard/Spatial panel modes, soft outer/card shadows, and the same ordinary
  rounded UI skin in both modes. Spatial provides persisted Fixed perspective
  and Drag to inspect choices. Hold the right button by default, or select the
  middle button/custom button and modifiers; release retains the angle. Cards
  retain proximity feedback, offset outlines and hollow shadows. A thin 2.5-DIP
  side layer adds panel thickness. Ordinary collapse keeps six toolbar buttons;
  four-edge auto-hide, enabled by default, restores through a small hover/click handle.
- Organized portable layout: three root files, documentation under `Docs`,
  notices under `Licenses`, and the .NET runtime bundled in the executable.
  Locales and component setup tools remain external. Fresh packages do not
  contain OCR binaries/models or an offline translation runtime/models.
- Screenshot Save, Extract text, and Extract and translate, with transient OCR,
  explicit copying, component guidance, cancellation and source-text retention.
- Separate Copy/Translate selection-bubble actions, source-session caching,
  clipboard-history suppression and temporary non-activating keyboard shortcuts.
- Explicit GitHub update checks, verified download/staging, same-path managed-file
  replacement, user-data snapshots, process identity checks and health-gated
  rollback/recovery. No silent installation or publisher signing was added.
- Twenty language packs and help text, nine READMEs, screenshot/upgrade guidance,
  ownership-manifest tooling and additional CI checks.

## Release fresh-install defaults

These defaults apply to new settings and fields absent from an older settings
file. Explicit saved preferences are preserved during load, save and upgrade.

| Setting | Default |
| --- | --- |
| Interface language | English |
| Show/hide panel / screenshot | Alt+Q / Alt+W |
| OCR and local translation | Not preinstalled; use Install / repair in Settings |
| Start with Windows | Off |
| Selection bubble / action | On / Copy |
| Translation provider | Google |
| Bubble style / text glow / shadow | Default / Off / On |
| Automatic clipboard collection / direct foreground paste | Off / Off |
| Auto-hide at a desktop edge | On |
| Collapse / expand delay | 2 seconds / 0.1 seconds |
| Theme / panel mode | Follow system / Standard |
| Spatial interaction / gesture | Drag to inspect / Hold right mouse button |
| Panel text colors / card opacity | Auto / 90% |
| Background image / overlay opacity | None / 20% |
| Frosted glass | Off; stored blur radius 4 px |
| Scheduled automatic backup | On, every 24 hours |

OCR Install / repair installs the verified native engine and English/Simplified
Chinese models under the current user's local application-data directory.
Offline translation retains its separate explicit installation action. Neither
component downloads during normal startup or screenshot saving. Legacy portable
OCR assets are preserved by the r7 update policy, alongside downloaded models
and offline translation assets. Earlier same-version candidates are replaced
manually; this policy does not retrofit their updater code.
