# KeeStashDock 1.2.1 acceptance record

Release date: **2026-10-12**. Release tag: **v1.2.1**.

## Scope and acceptance

This release packages the feature set previously validated as 1.1.2 candidates,
with version metadata, release documentation, demonstration images, and corrected
third-party attribution. The maintainer reported successful practical validation
on 2026-10-12 and accepted that remaining minor issues can be addressed in later
releases. This is general product acceptance, not a claim that every platform or
scenario below received separate manual verification.

## Validation

The fresh 1.2.1 Release build passed with **0 warnings and 0 errors**.
All **346 .NET tests** passed, with **0 failed and 0 skipped**. All **15 Python
helper tests** passed. The offline process-identity, native-runtime decision,
cleanup-protection, and publish-privacy scripts passed (28 privacy fixtures).
Sandbox restrictions initially prevented temporary-file access; the same tests
passed with access to their isolated test directories.

The corresponding GitHub Actions run is available from the
[release tag](https://github.com/Keegankei/KeeStashDock/tree/v1.2.1) and
[CI history](https://github.com/Keegankei/KeeStashDock/actions/workflows/ci.yml).
The release is published only after checking that run's result; local success alone is not a CI result.

Coverage includes:

- Data migrations, transactions, WAL imports, backup protections, Trash actions,
  image round trips, draft preservation, and current burn-after-read policies.
- WPF text input, panel visibility and rapid animation transitions, and real
  child-process single-instance notifications with isolated names.
- Component setup with a read-only application folder and retry after cancellation
  or timeout; offline request validation and process identity checks.
- Screenshot crops at negative coordinates and mixed synthetic scales, preserving
  original pixels. OCR cancellation, output bounds, and model checksums.
- Published executable startup from a path with spaces, an apostrophe, and an
  ampersand, followed by a replacement waiting for its disposable parent to exit.
- Package privacy checks, all 20 locale key sets and placeholders, dependency
  notices, and rejection of missing or corrupted required assets.

## Environment and limits

The local host was Windows 10 x64, build 19045. Windows 11 is the target platform;
Windows 10 behavior is best effort. No clean Windows 11 VM run is claimed.
Synthetic mixed-scale tests do not replace physical multi-monitor pointer checks.
The published-process test terminates its disposable parent and does not prove
Settings-button restart end to end. Clean-machine UAC/restart behavior and every
cloud provider/account combination were not separately certified in this run.

The standard ZIP is self-contained for .NET. It includes English/Simplified
Chinese OCR models and in-app installers, but offline translation still needs an
initial runtime/model download. Cloud services are subject to provider changes.
The executable is not code-signed; SHA-256 verifies the archive's integrity.

## Source and presentation review

The repository uses Apache-2.0 for original project content and retains separate
third-party terms. The legacy QR adaptation's attribution was corrected to MIT;
its original import revision is unknown and is not invented in the notice.
The .NET runtime notices were reconciled with the resolved release dependencies.

English is the default for source and documentation. README translations cover
Simplified Chinese, Traditional Chinese, and Japanese. Screenshots render real
WPF views with synthetic sample data; no personal desktop or clipboard content
is included. Translation files and README translations still benefit from native
speaker review.

The final source inventory contains **230 files** (225 UTF-8 text files and five
intended binary image/icon assets). JSON/XML parsing, local documentation links,
and diff formatting passed. Tracked files and reachable history were checked for accidental private/generated
paths and recognizable credential patterns. No matches were found in the reviewed
source. This is a bounded check, not proof that every possible secret or copyright
issue can be detected automatically.

## Distribution

The release asset is `KeeStashDock-1.2.1-win-x64.zip`, accompanied by
`KeeStashDock-1.2.1-win-x64.zip.sha256`. The clean 1.2.1 package passed verification of the runtime,
OCR binaries/models, local setup scripts, 20 locales, license texts, and absence
of personal state. The upload is staged in the existing private repository;
the owner controls when the repository becomes public.
