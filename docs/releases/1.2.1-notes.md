# KeeStashDock 1.2.1

A portable Windows x64 snippet manager with screenshot entries, local OCR,
optional offline translation, and in-app component setup.

## Download and run

1. Download **KeeStashDock-1.2.1-win-x64.zip** and its **.zip.sha256** file below.
2. Extract the complete ZIP into a writable folder and run **KeeStashDock.exe**.
   The .NET runtime is included; keep all bundled folders together.
3. Press **Alt+Q** to open the quick panel. Read **StartHere.md** in the package
   for first-use and component setup instructions.

## Highlights

- Save screen regions as image entries with **Ctrl+Alt+S** or the screenshot button.
- Recognize English/Simplified Chinese text locally, then edit or search it.
  Translation uses the existing selection bubble and your chosen provider.
- Install or repair OCR and optional English/Chinese offline translation from
  Settings, with progress, cancellation, and local engine start/stop controls.
- Use Alibaba Cloud, Baidu, DeepL, Bing China, or your configured local service.
- Includes fixes for direct paste targeting, multiline input, Trash actions,
  database imports, editor drafts, restart timing, and panel visibility.
- English documentation plus Simplified Chinese, Traditional Chinese, and
  Japanese README guides; 20 interface languages.
- A new application icon combines a continuous tricolor note-paper ribbon with
  a vintage quill. The maintainer approved the AI-generated design; its
  [provenance](https://github.com/Keegankei/KeeStashDock/blob/v1.2.1/docs/assets/README.md)
  is included in the repository.

## Upgrade and requirements

Back up your active data folder and close the old program before upgrading.
Extract into a fresh folder, then copy your complete old data into its **Data**
folder. If the old installation used **%AppData%\KeeStashDock**, copy that data
instead. This release migrates databases to schema v4; retain a pre-upgrade backup
if you need an older program that only supports schema v1-v3.

Windows 11 x64 is the target; local validation was performed on Windows 10 x64
build 19045, where support remains best effort. Local components may require the
Microsoft Visual C++ runtime; in-app setup handles the prerequisite and Windows
may request administrator approval or a restart. Offline translation requires an
initial download. Cloud providers may require credentials, quotas, or payment.
