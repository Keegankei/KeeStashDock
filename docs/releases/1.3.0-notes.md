# KeeStashDock 1.3.0

Release notes prepared for **v1.3.0**. Publication is pending; the latest
published release remains 1.2.3. See the [release validation record](1.3.0.md)
for CI results, artifact verification and outstanding acceptance checks.

Version 1.3.0 adds faster access to saved content, reusable templates, and a
coordinated appearance across the quick panel, workbench, Settings and bubbles.
Existing preferences are retained; illustrated themes remain optional.

## Download package

The stable release will provide these two files under **Assets**:

| File | Purpose |
| --- | --- |
| `KeeStashDock-1.3.0-win-x64.zip` | Complete portable Windows x64 application, including .NET |
| `KeeStashDock-1.3.0-win-x64.zip.sha256` | SHA-256 checksum for that exact ZIP |

Extract the full ZIP into a writable folder and run `KeeStashDock.exe`. Keep all
subfolders together. GitHub's **Source code** archives are for development.
Windows 11 is the primary target; Windows 10 22H2 has best-effort compatibility.
OCR and offline translation are optional downloads through **Settings > Local
components**, not preinstalled models.

To verify the download, compare this result with the sidecar file:

```powershell
Get-FileHash .\KeeStashDock-1.3.0-win-x64.zip -Algorithm SHA256
```

## Changes

- Theme preview/apply now matches the Settings card layout, with a rounded artwork preview, appearance switches, palette/control samples and a fixed action footer. Small windows stack the cards; missing artwork leaves no empty image panel. Preview cancellation and import-only behavior remain separate from applying settings.
- Redesigned the Default selection and result bubbles with segmented icon actions, subtle surface highlights, separate source/result cards, an explicit Copy button and grouped language/save controls. Wisteria Atelier builds on the same layout with pearl/lavender and deep-violet palettes. Bubble controls stay readable independently of the main theme, and high contrast removes decorative glow.
- Search directly in the quick panel without losing a capture draft. Filter by group, tag and item type, and load more results in pages of 50. Search input is debounced and obsolete responses are discarded.
- Organize multiple workbench items together: move groups, add/remove tags, pin/unpin, move to Trash and restore. Operations validate the entire selection in one transaction. Undo the most recent move to Trash during this session while its entries remain unchanged.
- Create reusable text templates with named fields and `{{date}}` / `{{time}}`. Review the expansion before copying; cancel leaves the template unused. Values are literal text, with no scripts, recursive expansion or external reads. Text templates and ordinary snippets can share the same source content.
- Apply a complete light/dark theme across the app, preview before applying, or import/export a theme ZIP. Choose Sunlit Gallery, Twilight Study, Wisteria Atelier or Wisteria Reverie, in that order. The first two feature quiet interiors; the other two feature illustrated conservatories and pianists. Each has day/night portrait and landscape artwork; System follows Windows light/dark appearance. Portrait art suits the quick panel; landscape art suits Settings and the workbench. Theme assets are optional and the default remains image-free.
- Adjust global text size from 90% to 150%. The workbench has a clearer navigation rail, editing surface, selection feedback and visible draft state. Dark-mode backup lists and progress indicators use the active palette.
- Settings > Appearance > Theme now has a separate Settings surface opacity slider (10–100%). It reveals theme artwork through cards, navigation and inputs without fading their text. Values are saved and included in complete theme exports; no-artwork and high-contrast views remain opaque.
- Translation results use a more compact layout with inline copy actions. Optional frosted backgrounds are available separately for Settings and bubbles: Settings softens its theme artwork with adjustable strength, while bubbles use the native compositor with an opaque fallback. Both are off by default and travel with complete theme exports. No desktop capture or continuous rendering timer is used for the effect.

## Upgrade from an earlier version

- **1.2.2 or 1.2.3:** after publication, use **Check for updates**, download and
  verify, then confirm **Restart and upgrade**. Manual replacement in a fresh
  folder is also supported.
- **1.2.1:** use the [manual upgrade procedure](../UPDATING.md#first-upgrade-from-121).
- **1.3.0 candidates, including r1–r5:** replace manually. Their numeric version
  is already 1.3.0, so the updater does not consider the final package newer.
  Exit the app first, keep the complete active data folder and custom theme
  exports, and re-register **Start with Windows** if the path changes.

The library moves to **schema v5**. Before modifying an existing database, startup makes and verifies an online SQLite backup, including committed WAL entries. Migration stops if the backup cannot be created. The snapshot lives beside the database under `Backups/pre_upgrade_v*_to_v5_*.db`, separately from automatic-backup retention.

**Version 1.2.3 and earlier cannot open a v5 library.** Keep the complete active data folder and pre-upgrade snapshot. Testing an older version requires a separate pre-upgrade database copy. Application-file rollback does not downgrade or overwrite the library, and the helper does not restart an older binary against an incompatible database. See [Updates and recovery](../UPDATING.md).

Group exports containing templates use format 3 and require 1.3.0 or newer; formats 1 and 2 remain importable. Complete theme exports are separate from database/group backups. `theme/builtin/` is managed by updates, while `theme/custom/` and theme staging/recovery files are preserved. Sharing a personal wallpaper through theme export requires explicit confirmation.

Existing language, shortcuts, window layout, fonts and optional components are retained. Fresh-install defaults remain English, Alt+Q / Alt+W, Standard mode, system theme, no background image, and no preinstalled OCR or offline-translation models.

New Settings surface opacity starts at **100%**, global text size at **100%**,
and Settings/bubble frosted effects at **Off**. Choosing a theme preset or
turning on an effect is explicit. **Follow interface language** remains the
translation-target default; the selection bubble starts in **Copy only** mode.

## Limits and validation

- Windows x64; .NET is bundled. The package remains unsigned, so Windows may show an unknown-publisher prompt. SHA-256 verifies archive integrity, not publisher identity.
- Template dialogs can invalidate the foreground application's direct-paste target. The app still copies the expanded text and reports that the target could not be safely verified; it does not paste into an unverified window.
- Ctrl+A in the workbench list selects loaded rows only. Batch permanent deletion, persisted desktop-note layout, screenshot editing and new OCR/translation models are outside this release.
- The README includes isolated English 1.3.0 WPF previews; older workflow GIFs
  and screenshots are labeled 1.2.3. These illustrations are not physical-desktop,
  animation-performance or clean-machine acceptance results.
- Native bubble blur depends on Windows composition and transparency support.
  Unsupported configurations keep an opaque readable background; the visible
  compositor effect still needs physical-desktop acceptance.

Build, automated tests, package checks and remaining manual coverage are recorded
in the [validation record](1.3.0.md). Local candidate validation does not establish
that the final release package or its GitHub CI has passed.
