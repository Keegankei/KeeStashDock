# KeeStashDock 1.2.2

A portable Windows x64 dock for snippets, screenshot entries, and text reuse.
Version 1.2.2 adds Spatial presentation, screenshot text actions, combined
selection controls, and verified in-app updates.

## Download and run

1. Download **KeeStashDock-1.2.2-win-x64.zip** and its matching **.zip.sha256** file
   from the official GitHub Release. The files become available after publication.
2. Compare the ZIP's SHA-256 with the checksum file, then extract the whole ZIP
   into a writable folder and run **KeeStashDock.exe**. The .NET runtime is included.
3. Keep all accompanying folders together. Read **StartHere.md** for first-use
   instructions. **Alt+Q** shows the panel; **Alt+W** starts a screenshot.

## Highlights

- Choose **Standard** or **Spatial** presentation. Spatial preserves the familiar
  controls while adding perspective, layered cards, soft shadows, and a thin
  panel edge. Use a fixed view or hold the right mouse button and drag to inspect;
  the middle button and custom gestures are also supported.
- Drag the panel to a desktop edge to tuck it into a small handle. Hover or click
  to restore it. The compact bar keeps all six toolbar actions.
- After selecting a screen region, choose **Save screenshot**, **Extract text**,
  or **Extract and translate**. Text-only extraction creates no library entry and
  does not copy automatically. Translation failures retain the recognized source.
- Choose **Copy and translate** for two separate selection-bubble buttons and
  reuse the same selected text for both actions.
- Use **Check for updates** from the tray or Settings. Downloads require an
  explicit action and are verified before a separate **Restart and upgrade**
  confirmation. Same-path upgrades preserve data and installed components, with
  application-file recovery if replacement or startup fails.
- Install optional OCR and local translation from **Settings > Optional
  components > Install / repair**. The standard package includes setup tools and
  notices, with no preinstalled optional engines, models, or runtimes.
- Read illustrated guides in English, Simplified Chinese, Traditional Chinese,
  Japanese, Korean, German, French, Spanish, and Brazilian Portuguese. The app
  provides twenty interface languages.

This version also fixes screenshot selection cancellation, narrow torn-out
notes, update checks when the GitHub API is limited, and selection-bubble
monitoring after a screenshot is saved or cancelled.

## First-use defaults

New settings start in English with **Alt+Q / Alt+W**, Google translation, and an
enabled **Copy only** selection bubble. Bubble styling is Default, text glow is
off, and shadow is on. Startup launch, automatic clipboard collection, and
direct paste are off. Edge auto-hide is on with **2 s / 0.1 s** delays.

Appearance follows the system theme in **Standard** mode. Spatial inspection
uses right-button dragging; text colors are automatic and controls opacity is
**90%**. There is no background image; the overlay is **20%** and frosting is off
with a stored **4 px** radius. Scheduled automatic backups run every **24 hours**.
Existing saved preferences are preserved during upgrades.

## Upgrade from 1.2.1 or an earlier 1.2.2 candidate

The first move from 1.2.1 is manual. Earlier 1.2.2 candidates also need manual
replacement because they share the final numeric version and are not recognized
as older versions by Check for updates.

1. Back up the active data folder. Stop any installed local translation service
   from Settings, then exit KeeStashDock from its tray menu.
2. Extract the full new package into a fresh folder. Copy the complete active
   data folder into the new installation's **Data** folder while the app is
   closed. If Settings identifies **%AppData%\KeeStashDock** as the active data
   location, use that folder as the source.
3. Start the new app and verify the library and settings. Update your shortcuts.
   If **Start with Windows** was enabled, turn it off and on again in the new
   app's Settings to register its new executable path. Otherwise the next Windows
   sign-in may start the old copy.
4. Keep the previous installation and backup until satisfied. Per-user components
   remain available; use **Install / repair** if a legacy portable component was
   not moved or is missing. Do not overwrite the new setup scripts with old ones.

Database schema v4 is unchanged from 1.2.1. Older programs that only support
schemas v1-v3 cannot open a v4 database. Application rollback does not roll back
the database. See the [upgrade and recovery guide](https://github.com/Keegankei/KeeStashDock/blob/v1.2.2/docs/UPDATING.md).

## Requirements and known limits

- Windows 11 x64 is the primary target; Windows 10 22H2 compatibility is best
  effort. See the [acceptance record](https://github.com/Keegankei/KeeStashDock/blob/v1.2.2/docs/releases/1.2.2.md) for the actual tested environment,
  build/test results, package checksum, and outstanding platform checks.
- Clean-machine Windows 11/UAC, full interactive upgrade/restart, and every GPU,
  DPI, physical input device, or translation provider combination have not all
  been independently validated. Synthetic UI fixtures do not establish this
  coverage.
- Initial OCR or local translation installation needs internet access and may
  require Microsoft's Visual C++ runtime, administrator approval, or a Windows
  restart. OCR supports printed English/Simplified Chinese; downloaded offline
  translation models support English and Simplified Chinese in both directions.
- Cloud translation sends the explicitly requested text to the chosen provider.
  Availability, credentials, quotas, and charges depend on that provider. Stored
  provider credentials in local **settings.json** are not encrypted. Local OCR
  and translation do not silently fall back to the cloud.
- The application is unsigned. Windows SmartScreen may show an unknown-publisher
  warning. SHA-256 checks download integrity; it is not a publisher signature.
