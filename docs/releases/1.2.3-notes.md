# KeeStashDock 1.2.3

Release date: **2026-10-19**. Windows x64 portable package, licensed under
Apache-2.0. Windows 11 is the primary target; Windows 10 22H2 compatibility is
best effort, with the tested scope recorded below.

Version 1.2.3 makes translation targets independent of the interface language,
lets you keep temporary text results, exposes backup status and shorter
intervals, and explains unavailable shortcuts. The redesigned Settings window
also groups preferences by task and lets you choose storage locations for
backups and optional components.

## Highlights

- **Independent translation target.** Choose a default target in Settings for
  selection, screenshot and test translations. **Follow interface language**
  preserves earlier behavior. Changing the target in a result window applies
  only to that result and translates the retained source again.
- **Save temporary results.** Choose a group and save the source, translation,
  or both. Both creates a single labeled text entry. Duplicate content reuses an
  existing entry in the chosen group. Saving does not copy text or save the
  screenshot; failures leave the result available. In translation settings,
  independently show or hide the temporary target selector and the Save to
  group panel. Both start enabled. Hiding controls does not clear the result
  or silently save it.
- **Backup status and shorter intervals.** Settings shows the last attempt,
  last success, next scheduled check, state, location and snapshot list. Use
  **Back up now**, open the backup folder, or restore a listed snapshot through
  the guarded import flow. Intervals include 15, 30 and 60 minutes, 6, 12, 24 and
  48 hours, and 7 days. The default remains 24 hours.
- **Actionable shortcut conflicts.** If the panel or screenshot shortcut fails
  at startup, a combined tray notification opens Settings. Persistent status
  identifies the affected combination. Tray actions remain available and a
  failed shortcut replacement keeps the previous working binding.
- **Settings organized around tasks.** A navigation sidebar separates general,
  translation, appearance, component, data and About preferences. Related
  options appear when applicable, including Spatial inspection, custom colors,
  background-image effects and automatic backup scheduling. Shared translation
  and manual backup actions remain available when their other entry points are off.
- **Choose component and backup folders.** Change or reset the destination for
  database snapshots, OCR and offline translation from Settings. OCR uses
  `OcrModels` and `OcrEngine` inside its selected folder; offline translation uses
  its selected folder as the runtime. Old files remain where they are. Select a
  valid existing component installation to reuse it, or an empty folder and
  choose **Install / repair**. Changing location does not download, move or
  delete components.
- **Reliable panel startup.** Fixes the unhandled null-reference dialog that
  could appear in 1.2.2 when first opening the panel after restarting with a
  saved screen position. The panel restores its position and registers its
  native resize/move handling without waiting for the visual tree to attach.
- **Resize at visible edges.** Spatial panels now resize from their visible
  edges and corners after perspective inspection, as well as the outer window
  frame. Grab areas scale with monitor DPI and preserve physical resize
  directions in right-to-left layouts. The compact bar remains fixed-size.

## Upgrade and defaults

The database remains at schema v4. Keep the active data folder and any installed
optional components. Existing interface language, provider credentials,
shortcuts, backup retention and valid custom hourly intervals are preserved.
Minute-based settings take precedence after migration. Keep pre-upgrade
settings when downgrading to an older app that cannot use minute intervals.

Fresh installations still use English, Alt+Q / Alt+W, Google translation,
**Follow interface language**, and automatic backups every 24 hours. OCR and
local translation remain optional downloads. Language coverage is unchanged:
printed English/Simplified Chinese OCR and English/Simplified Chinese offline
translation in both directions. Choosing an unsupported direction does not
silently switch to cloud translation.

Custom folder preferences are absolute paths specific to the current machine.
After moving to another computer or removing a drive, select a valid destination
or use its reset action. A component path change is validated before it is saved;
the old offline service must stop successfully first. Backup history and retention
apply to the selected backup folder, and switching folders leaves earlier files
intact. The active library/settings folder is shown with an open-folder action;
these preferences do not relocate it. Export still uses the destination you choose
for that export.

The chosen backup location covers automatic/manual database snapshots and
pre-import safety backups. Full update-recovery snapshots remain under the active
data folder's `Backups/BeforeUpdate-*`, independent of this choice. Update recovery
does not duplicate known backups or optional component payloads placed inside the
data folder; unrelated user files beside them are still copied.

An automatic backup is a complete SQLite snapshot, including stored images and
OCR text. It is not a backup of settings, downloaded components, backgrounds or
desktop layout. Scheduling runs only while the application is open. Startup or
resume performs at most one overdue attempt; repeated failures are spaced out.
Seven snapshots at 15-minute intervals span about 90 minutes from oldest to
newest. Automatic retention preserves manual and recovery snapshots.

## Package and validation

Extract the complete Windows x64 ZIP and run `KeeStashDock.exe`. Keep its folders
and ownership manifest together. Use the matching SHA-256 file to check download
integrity; the application remains unsigned.

See the [acceptance record](1.2.3.md) for the tested build, package and remaining
manual coverage, and [upgrade instructions](../UPDATING.md) for same-path updates,
manual replacement and recovery. Download the Windows x64 ZIP and matching
SHA-256 sidecar from the [v1.2.3 release page](https://github.com/Keegankei/KeeStashDock/releases/tag/v1.2.3).

Version 1.2.2 can upgrade through **Check for updates**. Earlier local 1.2.3
candidates share the final numeric version and require manual replacement.
Exit the older tray instance first; keep the active data folder and installed
components when replacing the package.
