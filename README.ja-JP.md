## ダウンロードと起動

**[最新リリース](https://github.com/Keegankei/KeeStashDock/releases/latest)** ·
**[1.2.1 Windows x64 版をダウンロード](https://github.com/Keegankei/KeeStashDock/releases/download/v1.2.1/KeeStashDock-1.2.1-win-x64.zip)** ·
[SHA-256 チェックサム](https://github.com/Keegankei/KeeStashDock/releases/download/v1.2.1/KeeStashDock-1.2.1-win-x64.zip.sha256)

1. リリースページの **Assets** からアプリの ZIP をダウンロードします。GitHub が生成する **Source code** アーカイブは開発者向けです。
2. ZIP 全体を書き込み可能なフォルダーに展開し、`KeeStashDock.exe` を実行します。付属のファイルやフォルダーも一緒に置いてください。
3. **Alt+Q** でクイックパネルを開きます。Windows の通知領域からもアクセスできます。
4. 「設定」で言語、外観、必要なコンポーネントを選びます。

パッケージは **Windows x64** 向けで、.NET ランタイムを同梱しています。Windows 11 を推奨し、Windows 10 22H2 との互換性はベストエフォートで対応します。OCR とオフライン翻訳には Microsoft Visual C++ ランタイムが必要な場合がありますが、アプリ内のインストール機能で導入できます。検証範囲と制限は[変更履歴](CHANGELOG.md)と[受け入れ検証記録](docs/releases/1.2.1.md)を参照してください。

## 基本的な使い方

| 操作 | 方法 |
| --- | --- |
| クイックパネルの表示・非表示 | **Alt+Q**。設定で変更可能 |
| 入力したテキストの保存 | クイック入力欄で **Enter** |
| 改行 | **Alt+Enter** または **Shift+Enter** |
| テキスト項目のコピー | カードをクリック。直接貼り付けは任意で有効化 |
| 範囲キャプチャ | キャプチャボタンまたは **Ctrl+Alt+S**。ドラッグで範囲選択、**Esc** または右クリックでキャンセル |
| 画像項目を開く | カードをクリックしてプレビュー、コピー、保存、文字認識 |
| 項目の整理 | ワークベンチで検索、グループ分け、タグ付け、ピン留め、編集、復元 |
| 選択テキストの翻訳 | 設定で選択バブルを有効にし、「翻訳」と翻訳サービスを選択 |

付箋、QR コード、テキスト変換、グループのインポート・エクスポート、保存期限、任意のクリップボード履歴にも対応しています。クリップボード履歴と直接貼り付けは初期状態では無効です。インターフェイスには 20 の言語パックがあり、ライト、ダーク、システム連動のテーマを選べます。

## OCR とオフライン翻訳の初回セットアップ

通常はアプリ内のボタンだけで設定でき、ターミナルのコマンドは不要です。

1. **設定 > 追加コンポーネント** を開きます。
2. OCR で不足するコンポーネントがあると表示された場合は、**文字認識（中国語 / 英語）** の **インストール / 修復** を押します。標準 ZIP にはエンジンと英語・簡体字中国語のモデルが含まれており、インストーラーはネイティブランタイムも確認します。
3. オフライン翻訳を使う場合は、**オフライン翻訳（中国語 / 英語）** の **インストール / 修復** を押します。ダウンロードと検証が完了するまで設定画面を開いたままにしてください。約 **1 GB の空きディスク容量**と **2 GB の利用可能なメモリ**を用意します。
4. Windows が Microsoft ランタイムのインストール許可を求めた場合は、インストーラーの案内に従います。再起動が必要と表示された場合は Windows を再起動し、コンポーネントのセットアップを再実行してください。アプリでキャンセルしても、開始済みの Windows ランタイムのインストールは取り消されません。
5. 翻訳エンジンをローカルオフラインに変更し、アドレス `http://127.0.0.1:5000` を保持して翻訳テストを実行します。インストール済みエンジンは必要時に起動し、設定の「サービスを開始」「サービスを停止」でも操作できます。

初回ダウンロードには、選んだコンポーネントに応じて GitHub、python.org、files.pythonhosted.org、argos-net.com、必要なら Microsoft の配布サイトへの接続が必要です。ネットワークによっては接続できない場合があります。失敗後は再試行でき、検証済みのキャッシュは再利用されます。セットアップ後の文字認識とローカル翻訳はオフラインで動作します。アプリを終了しても、翻訳サービスは停止するまで動作し続けます。

OCR は印刷された**英語と簡体字中国語**に対応します。同梱の翻訳モデルは**英語 ↔ 簡体字中国語**用です。**日本語、繁体字中国語、その他すべての UI 言語への翻訳には対応していません。** OCR は自動では翻訳しません。認識結果を選択して翻訳バブルを使ってください。モデルが不足してもクラウド翻訳へ自動的に切り替わることはありません。

詳細は [OCR の設定と制限](docs/LOCAL_OCR.md)、[オフライン翻訳の設定とトラブルシューティング](docs/OFFLINE_TRANSLATION.md)、[スクリーンショットの操作](docs/SCREENSHOTS.md)を参照してください。詳細なプロジェクト文書は英語です。

## 翻訳サービスとプライバシー

- **Bing（中国）、Google、Lingva：** キー不要の選択肢ですが、継続的な利用可能性は保証されません。新規インストールの既定値は Bing で、既存の設定は保持されます。
- **Baidu、Alibaba Cloud、DeepL：** 自分の認証情報を使用します。無料枠や料金はアカウントの条件に従います。Alibaba Cloud では機械翻訳サービスの有効化と `alimt:TranslateGeneral` 権限が必要です。
- **ローカルオフライン：** インストール済みエンジンをループバック経由で使用します。アカウントや API 料金は不要です。

テキスト、画像、認識結果、バックアップは PC に保存され、OCR は画像をアップロードしません。クラウド翻訳は選択したテキストを指定したサービスにだけ送信し、別のサービスへ自動転送しません。認証情報はローカルの `settings.json` に**平文**で保存されます。入力欄のマスク表示は暗号化ではありません。外部サービスに送信する前に、その内容を開示してよいか確認してください。

オフライン翻訳はループバックアドレスのみを受け付け、HTTP プロキシを経由せず、リダイレクトを拒否します。同梱エンジンは翻訳中にモデルをダウンロードしません。脆弱性の非公開報告については[セキュリティポリシー](SECURITY.md)をご覧ください。

## データ、バックアップ、更新

データは通常、実行ファイルの隣の `Data` フォルダーに保存されます。データベース、設定、下書き、ログ、バックアップが含まれます。アプリのフォルダーに書き込めない場合は `%AppData%\KeeStashDock` が使われ、設定画面に案内が表示されます。アプリ内で導入するコンポーネントは通常 `%LOCALAPPDATA%\KeeStashDock` に保存され、項目データとは別に管理されます。

更新前に次の手順を行ってください。

1. **設定 > データ** でバックアップをエクスポートし、通知領域のメニューから KeeStashDock を終了します。
2. 新しい ZIP を別のフォルダーに展開します。ポータブル構成では、アプリを閉じた状態で旧版の **`Data` フォルダー全体**を新しいフォルダーにコピーします。旧版は復元用に残してください。
3. 設定が `%AppData%` の使用を示している場合は、そのフォルダーもバックアップします。書き込み可能なポータブルフォルダーに移る場合は、初回起動前にその内容全体を新しい `Data` フォルダーへコピーしてください。コピーしないと空のライブラリが表示される場合があります。
4. 新版を起動して項目を確認し、問題がないと確認するまで旧版とバックアップを残します。旧版に戻すときは更新前のバックアップを使い、更新済みデータベースを旧版で直接開かないでください。

Issue に実際の `Data` フォルダー、認証情報、非公開のバックアップやログを添付しないでください。機密情報を除いた報告方法は[サポートガイド](SUPPORT.md)をご覧ください。

## ビルドと貢献

Windows と、`global.json` が指定する **.NET SDK**（10.0.401 または互換性のある 10.0.4xx パッチ版）を使用します。

```powershell
dotnet restore KeeStashDock.sln
dotnet build KeeStashDock.sln --configuration Release --no-restore --disable-build-servers
dotnet test --solution KeeStashDock.sln --configuration Release --no-build
```
